# Fantasy Bet — Demo

A mobile sportsbook-style demo for a fantasy football league: friends bet their seasonal fantasy points (not real money) against each other on weekly matchups — Moneyline, Spread, and Totals.

This is a single self-contained `index.html` (fonts and data included) so it doesn't need a server. Once GitHub Pages is enabled for this repo, it's live at:

```
https://mattyanko.github.io/fantasy-bet-demo/
```

Mock data only — no real league integration yet.
